# Motiv8 화면·시각 기준

## 상태와 목표

- 현재 웹으로 개발하고 이후 앱 전환을 고려한다. 모바일에서 앱처럼 보이고 조작하기 쉬운 화면을 기본으로 한다.
- 지금까지 확인한 홈·운동 목업의 분위기를 디자인 출발점으로 삼는다. 실제 UI 구현 완료를 뜻하지 않는다.
- 캐릭터 육성이 서비스의 중심 차별점이다. 홈에서 캐릭터를 먼저 보이게 한다.

## 시각 분위기

- 밝은 크림색 바탕, 부드러운 민트색 주요 영역, 진한 녹색 강조를 기본 조합으로 삼는다.
- 둥근 카드와 버튼, 넉넉한 여백, 얕은 그림자와 낮은 대비의 구분선을 사용한다.
- 운동 기록은 정보가 많으므로 장식보다 값·완료 상태의 판독성을 우선한다.
- 민트 농도는 의미를 일관되게 쓴다. 예: 홈 달력의 연한 민트는 운동 완료, 진한 민트는 하루 목표 모두 완료.
- 성공·오류·비활성 상태를 색상만으로 구분하지 않고 텍스트나 아이콘도 함께 쓴다.
- 정확한 색상 코드, 타이포그래피, 간격과 그림자 수치는 실제 화면에서 확인 후 토큰으로 확정한다.

## 공통 화면 구조

- 좁은 휴대폰 화면을 우선 설계하고, 넓은 화면에서는 콘텐츠 최대 폭을 제한한다.
- 기기별 세로 비율 차이를 고려한다. 주요 콘텐츠는 스크롤되고 하단 탐색은 화면 최하단에 고정한다.
- 하단 안전 영역을 확보해 홈 인디케이터와 탐색 버튼이 겹치지 않게 한다.
- 하단 탐색: `홈 · 운동하기 · 루틴 · 기록 · 마이`. 아이콘과 짧은 이름을 함께 표시한다.
- `루틴` 안에서 루틴 등록·관리와 운동 종목 등록을 다룬다.
- 터치 영역은 충분히 크게 잡고, 작은 칸에 값 편집과 완료 동작을 겹치지 않는다.

## 홈 목업

- 캐릭터를 화면 상단의 주인공으로 배치하고 성장 상태를 함께 보여준다.
- 알림 아이콘 아래에 첫 운동 기록일부터 센 `D+N`을 표시한다. 가입일은 기준으로 쓰지 않는다.
- 캐릭터 영역을 크게 강조한다. 그 아래 같은 크기의 카드 두 개에 8각형 성장 스탯과 간략 달력을 좌우로 배치한다.
- 스탯 축은 `어깨 · 팔 · 가슴 · 등 · 복근 · 하체 · 지구력 · 열정`이다.
- 스탯 값과 열정 계산 정책은 백엔드가 제공한다. 프론트는 반환값을 임의로 재계산하지 않는다.
- 기록 달력은 오른쪽 카드에 간략하게 표시한다. 월별 요일·날짜와 달성 상태를 남긴다.
- 오늘과 선택 날짜는 완료 색과 별도의 테두리 또는 강조 상태로 구분한다.
- 날짜를 누르면 해당 날짜의 운동·목표 상세로 이어진다.
- 운동 시작 동작을 쉽게 찾을 수 있게 둔다.
- 하루 목표 체크박스 기능은 향후 확장 아이디어다. 세부 데이터와 화면은 아직 확정하지 않았다.

## 운동 화면 목업

- 상단: 루틴 이름, 운동 추가·불러오기, 운동 시간, 전체 세트 진행 상태.
- 필터: `전체 · 맨몸 · 웨이트 · 유산소 · 완료`. 완료 운동은 완료 필터로 이동한다.
- 운동은 유형과 타겟 부위가 보이는 카드 목록으로 표시한다.
- 웨이트 카드는 세트별 중량·반복을 따로 편집하고, 완료 표시를 별도 터치 영역으로 둔다.
- 세트가 많으면 카드 안에서 세트 영역을 가로로 탐색할 수 있다. 세트 번호는 항상 보이게 한다.
- 마지막 세트 옆 `+`로 세트를 추가한다. 직전 세트 값을 복사하고 새 세트는 미완료로 시작한다.
- 맨몸 카드는 반복 위주로, 추가 중량은 사용 체크 후 입력한다. 유산소는 타이머 위주로 표시한다.
- 운동을 전부 완료하면 카드 이동을 잠시 안내한다. 완료 필터에서 상태를 되돌릴 수 있다.
- 운동 중 일시정지·운동 완료 동작은 하단 탐색보다 위에 두고, 스크롤 콘텐츠와 겹치지 않게 한다.

## 구현 전에 확인할 것

- 실제 기기 너비·높이와 브라우저 하단 영역에서 카드, 버튼, 달력의 잘림 여부.
- 세트가 많은 운동에서 가로 탐색과 값 편집의 사용성.
- 달력의 색 의미가 색각 차이·저대비 화면에서도 구분되는지.
- 캐릭터 로딩 중, 운동 기록 저장 중, 네트워크 실패 상태의 화면.
