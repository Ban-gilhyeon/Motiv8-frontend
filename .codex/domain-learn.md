# 도메인 지식 진입점

이 프로젝트의 상세 도메인 문서는 기존 `.codex/domain/` 구조를 유지한다.
동일한 요구사항을 이 파일에 중복 작성하지 않는다.

- [도메인 목록](domain/index.md)
- [운동 종목](domain/exercise.md): 유형·측정값·맨몸 추가 중량·웨이트 소분류.
- [운동 기록](domain/workout.md): 루틴과 실제 수행 기록의 분리.
- [운동 수행 화면](domain/workout-session.md): 사용자가 정의한 운동 시작·루틴 불러오기·카드·세트 게이지 흐름.

문서의 미정 사항이나 구현 제안을 확정 API 계약으로 해석하지 않는다.
