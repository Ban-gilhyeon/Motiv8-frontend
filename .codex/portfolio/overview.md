# 프로젝트 개요

Motiv8은 운동 기록을 바탕으로 운동 일지, 통계, 아바타 진행도, 추천과 알림을 제공하는 서비스다.

## 프론트엔드 역할

- 사용자 행동을 운동 기록 흐름으로 연결한다.
- 서버 도메인 규칙을 입력 UI와 상태 화면에 반영한다.
- API 응답을 로딩·성공·빈 상태·오류 상태로 표현한다.
- 인증 사용자에게 개인 데이터를 안전하게 제공한다.

## MVP 화면 후보

- 회원가입·로그인
- 운동 종목 조회
- 루틴 관리
- 운동 기록 입력
- 월별 운동 일지
- 부위별 통계

추천·알림·배지·친구 경쟁은 API 계약 확정 후 확장한다.
