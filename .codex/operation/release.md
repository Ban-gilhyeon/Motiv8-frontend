# 배포 점검

## 계약

- 운영 API base URL 확인
- `/api/v1` 중복 여부 확인
- CORS·쿠키·HTTPS 설정 확인
- 인증 만료·refresh 실패 흐름 확인
- 400·401·403·404·409·500 화면 확인

## 기능

- 회원가입·로그인·로그아웃
- 운동 종목 조회
- 루틴 생성·수정
- 운동 기록 저장·수정·삭제
- 월별 일지와 통계
- 기록 없는 상태와 서버 오류

## 운영

- source map 공개 정책 확인
- 환경변수 노출 점검
- 콘솔 로그 제거 또는 레벨 제한
- 오류 모니터링 이벤트 개인정보 마스킹
- 새로고침·직접 URL·뒤로가기 확인

- 배포 명령과 CI 절차
- smoke test 자동화 범위
