# 운동 수행 화면 요구사항

## 문서 상태

사용자가 설명한 운동 측정·기록 흐름이다. UI 요구사항이며 API 구현 완료를 의미하지 않는다.
확정 요구사항과 제안·미정 항목을 구분한다.

## 진입과 루틴

- 운동 시작 시 오늘 루틴을 불러온다.
- 루틴 안에는 운동 목록이 있다.
- 저장 가능한 루틴은 약 3~5개를 고려한다. 정확한 개수는 미정이다.
- 운동 대분류에 관계없이 루틴에 저장된 모든 운동을 불러온다.

## 상단 배치

1. 최상단 왼쪽: 루틴 이름.
2. 최상단 오른쪽: 운동 추가 또는 불러오기.
3. 그 아래: 총 운동 시간.
4. 그 아래: 루틴에 설정된 전체 운동 할당량 진행 게이지.
5. 그 아래: 필터·정렬과 운동 카드 목록.

총 운동 시간이 경과 시간인지 예상 시간인지, 타이머 시작·일시정지 기준은 미정이다.
전체 할당량 게이지는 완료 세트 수와 전체 세트 수를 보여준다. 유산소 반영 방식은 미정이다.

## 운동 추가·불러오기

- 운동을 추가하거나 다른 루틴에 있는 운동을 불러올 수 있다.
- 체크박스로 원본 루틴에 계속 포함할지, 오늘만 적용할지 선택한다.
- 원본 루틴과 오늘 수행 목록은 분리한다.
- 원본 루틴의 변경이 이미 작성한 기록을 덮어쓰면 안 된다.
- 오늘만 적용을 기본값으로 두는 것은 제안이며 아직 확정하지 않았다.

## 목록과 탐색

- 운동 하나를 카드 하나로 표시한다.
- 운동 유형과 타겟 부위를 기준으로 정렬한다.
- 필터는 `전체 · 맨몸 · 웨이트 · 유산소 · 완료`를 제공한다.
- `전체`와 유형별 필터에는 진행 중이거나 시작하지 않은 운동만 표시한다.
- 모든 세트를 끝낸 운동은 `완료` 필터에서만 표시한다. 완료는 원본 루틴에서 삭제를 뜻하지 않는다.
- 마지막 세트를 완료해 카드가 이동하면 잠시 안내를 보여준다. 완료 필터에서 완료를 취소할 수 있다.
- 필터는 표시 목록에만 적용하고 원본 루틴에서 운동을 제거하지 않는다.
- 사용자는 긴 목록을 스크롤로 탐색하는 방식을 선호한다.
- 루틴 목록 전체를 한 번에 읽고 일반 세로 스크롤로 표시하는 것은 구현 제안이다.
- 실제 페이지네이션·추가 로딩 필요성은 운동 수와 API 계약에 따라 결정한다.

## 운동 카드

| 정보 | 표현 |
|---|---|
| 운동 이름 | 카드 제목 |
| 대분류 | 맨몸·웨이트·유산소 |
| 타겟 부위 | 종목에 설정된 부위 |
| 세트 수 | 세트 개수만큼 나눈 게이지 칸 |
| 세트당 반복 | 각 세트에 개별 표시·수정 |
| 세트 완료 | 값 편집과 분리된 완료 영역을 터치하면 채움 |
| 웨이트 무게 | 각 세트에 개별 표시·수정 |
| 웨이트 소분류 | 머신·프리 |
| 세트 추가 | 마지막 세트 옆 `+` 버튼 |

예: 목표가 3세트이고 세트당 12회라면 `12회 / 12회 / 12회` 세 칸을 표시한다.
단순 숫자 세트 수만 표시하는 방식보다 시각적인 완료 진행을 우선한다.

### 세트 추가

- 해당 운동 카드의 마지막 세트 옆 `+`를 누르면 세트 하나를 추가한다.
- 새 세트는 직전 마지막 세트의 무게와 반복 횟수를 복사한다. 복사 후 수정할 수 있다.
- 맨몸은 반복 횟수와 추가 중량 사용 여부·값을 복사한다.
- 유산소는 직전 타이머 목표 설정을 복사한다. 유산소 세트 모델은 추가 정의가 필요하다.
- 새 세트는 미완료로 시작한다. 전체 진행 게이지의 전체 세트 수도 즉시 늘어난다.
- 세트 추가가 원본 루틴에도 반영되는지, 오늘 운동에만 반영되는지는 별도 정책으로 정한다.

## 운동 유형별 동작

### 웨이트

- 세트 수, 세트당 반복 횟수, 중량을 설정한다.
- 머신 또는 프리 소분류를 표시한다.
- 세트마다 중량과 반복 횟수를 따로 설정한다. `전체 세트에 적용`으로 같은 값을 한꺼번에 넣을 수 있다.

### 맨몸

- 기본 입력은 세트 수와 세트당 반복 횟수다.
- 기본 상태에서는 중량 입력을 막는다.
- 추가 중량 사용 체크박스를 선택하면 중량 입력을 허용한다.
- 추가 중량이 있어도 맨몸 유형을 유지한다.

### 유산소

- 중량은 표시하지 않는다.
- 타이머를 사용한다.
- 타이머 조작, 목표 시간, 세트 게이지 적용 여부는 추가 정의가 필요하다.

## 추가 결정 사항

- 오늘 루틴 지정 방식과 저장 가능한 정확한 루틴 상한.
- 필터·정렬의 우선순위, 같은 부위 내 운동 순서와 순서 편집.
- 세트 완료 취소, 실제 반복 횟수가 목표와 다른 경우 입력 방식.
- 운동 추가·삭제 시 전체 할당량 분모 변경 기준과 유산소 환산 방식.
- 다른 루틴에서 불러올 때 목표 세트·중량 복사 범위와 중복 종목 처리.
- 타이머의 백그라운드·화면 잠금·재진입 처리.
- 진행 중 자동 저장, 중단·재개·운동 종료 흐름.
- 세트 터치가 즉시 서버 저장인지 임시 완료 표시인지 여부.
