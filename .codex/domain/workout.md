# 운동 기록 도메인

## 핵심 개념

- `Routine`: 반복 수행할 계획
- `Set`: 루틴 또는 기록 안의 한 세트
- `Workout Record`: 특정 날짜에 실제 수행한 결과
- `Workout Journal`: 날짜별 기록 조회
- `Volume`: 기간 또는 부위별 누적 운동량

## 사용자 흐름

1. 운동 시작 시 오늘 루틴과 루틴에 포함된 운동 목록을 불러온다.
2. 유형과 타겟 부위로 목록을 정리하고, 필요 시 운동을 필터링한다.
3. 유형별 목표와 측정값을 확인·입력한다.
4. 세트 게이지를 터치해 해당 세트를 완료 상태로 표시한다.
5. 기록 저장 성공 시 일지·통계·진행도를 재조회한다.
6. 날짜 선택 시 해당 날짜 상세를 표시한다.

세부 화면 요구사항은 [운동 수행 화면](workout-session.md)을 따른다.

## 루틴과 오늘 운동

- 루틴에는 반복 수행할 운동 목록과 목표 할당량을 저장한다.
- 저장 가능한 루틴은 약 3~5개를 고려하며 정확한 상한은 미정이다.
- 원본 루틴 설정과 오늘 실제 수행 기록은 분리한다.
- 운동 추가 또는 다른 루틴의 운동 불러오기를 지원한다.
- 체크박스로 원본 루틴에도 포함할지, 오늘 운동에만 적용할지 선택한다.
- 기본 선택 상태와 복사·중복 처리 방식은 미정이다.

## UI 규칙

- 루틴 편집 상태와 실제 기록 상태를 분리한다.
- `WEIGHT`는 무게·반복, `BODYWEIGHT`는 세트·세트당 반복, `CARDIO`는 타이머 기반으로 입력한다.
- 맨몸 운동의 추가 중량은 사용 체크박스를 선택한 경우에만 입력한다.
- 기록 없는 날짜·기간은 0 또는 빈 목록으로 표시한다.
- 수정·삭제 후 서버 재조회 결과를 우선한다.
- 저장 중 중복 제출을 막고 실패 시 입력을 보존한다.
