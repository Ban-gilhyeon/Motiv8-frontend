# 알림·소셜 도메인

## 알림

- 운동 리마인드, 영양 안내, 부족 부위 제안, 목표 달성 알림이 있다.
- 같은 조건의 반복 알림을 UI에서 임의로 중복 생성하지 않는다.
- 사용자는 알림 종류와 수신 여부를 조정할 수 있어야 한다.
- 웹 푸시 권한 요청은 사용자 행동 이후 별도로 진행한다.

## 소셜

- 운동 기록은 기본 비공개다.
- 사용자가 허용한 데이터만 친구에게 공개한다.
- 개인 신체 정보와 인증 정보는 공유·경쟁 대상이 아니다.
- 친구 관계와 기록 공개 권한은 별개다.
- 차단·연결 해제 시 공유 데이터 접근 상태를 갱신한다.

## 초기 범위

알림 조건 조회와 설정 화면을 우선한다. 친구·경쟁·실제 웹 푸시는 MVP 이후로 둔다.
