# 운동 종목 도메인

## 운동 유형

- `WEIGHT`: 무게와 반복 횟수
- `BODYWEIGHT`: 세트·세트당 반복 횟수, 선택적으로 추가 중량
- `CARDIO`: 시간, 필요 시 거리·속도·칼로리

초기에는 하나의 운동 종목이 하나의 유형만 가진다.

## 유형별 세부 정보

- 타겟 부위: 팔·등·가슴·어깨·하체·복근·유산소. 서버 enum 매핑은 별도 확인한다.
- 웨이트 소분류: 머신 또는 프리. API 필드·enum은 아직 확정하지 않았다.
- 맨몸 운동은 추가 중량을 사용해도 운동 유형을 변경하지 않는다.
- 추가 중량 사용 체크 전에는 중량 입력을 비활성화한다.
- 유산소는 타이머를 표시하며 중량 입력은 제공하지 않는다.

백엔드 기존 문서의 맨몸 중량 금지 규칙과 달라진 요구사항이다.
API가 추가 중량을 허용하는지 확인하고 백엔드 계약을 조정해야 한다.

## 측정 방식

- `weight-and-repetition`
- `bodyweight-and-repetition`
- `duration`
- `distance-and-duration`

## 프론트 동작

- 운동 유형에 맞는 입력 필드만 노출한다.
- 음수와 명백한 범위 오류를 입력 단계에서 막는다.
- 서버 검증이 최종 기준이다.
- 운동 정의와 실제 기록 UI 모델을 분리한다.

## 예외 상태

- 이름 없음 또는 중복
- 타겟 부위 없음
- 유형과 맞지 않는 측정값
- 필수 측정값 누락
