# 도메인 문서 목록

- [인증](auth.md): 사용자와 개인 데이터 소유권
- [운동 종목](exercise.md): 운동 유형과 측정값
- [운동 기록](workout.md): 루틴, 세트, 일지, 통계
- [운동 수행 화면](workout-session.md): 루틴 불러오기, 운동 카드, 세트 게이지, 타이머
- [진행과 추천](progress.md): 목표, 캐릭터, 배지, 추천
- [알림과 소셜](engagement.md): 알림, 친구, 공유

도메인 문서는 사용자 규칙을 기록한다. API 필드는 `api/` 문서를 기준으로 한다.
