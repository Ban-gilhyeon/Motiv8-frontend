# 인증 도메인

## 범위

회원가입, 로그인, 인증 상태, 개인 운동 데이터 접근을 다룬다.

## 사용자 규칙

- 인증된 사용자만 개인 운동 데이터를 볼 수 있다.
- 사용자는 자신의 기록만 생성·수정·삭제·조회할 수 있다.
- 다른 사용자의 ID를 알아도 개인 데이터를 조회할 수 없다.
- 비밀번호·토큰은 화면, 로그, URL에 노출하지 않는다.

## 화면 흐름

1. 회원가입 또는 로그인
2. 성공 시 인증 상태 저장·복원
3. 보호 라우트 진입 허용
4. 토큰 만료 시 갱신
5. 갱신 실패 시 로그아웃 후 로그인 이동

## UI 상태

- `unknown`: 앱 시작 시 인증 복원 중
- `authenticated`: 보호 화면 접근 가능
- `unauthenticated`: 로그인 필요
- `refreshing`: 토큰 갱신 중 중복 이동 금지
