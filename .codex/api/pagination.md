# 페이지네이션과 날짜

## 목록

- 목록 API는 기본 pagination을 전제로 한다.
- page size는 UI가 무제한 요청하지 않는다.
- 정렬 필드·방향을 API별로 명시한다.
- 초기에는 offset pagination을 우선 지원한다.
- `meta`의 현재 페이지, 크기, 전체 개수 또는 다음 페이지 여부를 사용한다.

## 날짜 조회

- 서버 저장 시각과 사용자 표시 날짜를 분리한다.
- 월별 운동 일지는 사용자 timezone 기준 날짜를 사용한다.
- 날짜 범위 시작·종료 포함 여부를 API 계약에 맞춘다.
- 기록 없는 날짜는 오류가 아닌 빈 결과로 표시한다.

## UI 원칙

- page·필터 변경 시 이전 목록과 새 목록을 혼동하지 않는다.
- 오래된 응답이 최신 상태를 덮지 않도록 취소 또는 query key를 사용한다.
- 통계 숫자와 날짜는 서버 계산 결과를 우선한다.
