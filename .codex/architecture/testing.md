# 테스트 경계

## 단위 테스트

- 운동 유형별 입력 검증
- API 응답의 화면 모델 변환
- 에러 코드별 사용자 상태 매핑
- 페이지네이션·날짜 범위 계산

## 통합 테스트

- API client 인증 헤더
- `401` refresh와 실패 시 로그아웃
- 로그인·로그아웃·보호 라우트
- 기록 저장 후 목록·통계 갱신

## 화면 테스트

- 로딩·빈 상태·오류 상태
- 운동 유형별 입력 필드
- 접근성 가능한 오류 표시와 제출 방지

## 금지

- 서버 응답을 무조건 성공으로 가정하지 않는다.
- 실제 토큰을 fixture에 넣지 않는다.
- 날짜·시간대 테스트는 고정 clock/timezone을 사용한다.
